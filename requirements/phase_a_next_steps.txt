### **MAJOR DEVELOPMENT (Week 3-4): Implement Homeroom Intelligence**

#### **Step 4: Auto-Assignment Backend Logic**
**Goal:** Build the core homeroom auto-assignment system

**Backend Development:**
```python
# New API endpoints needed:
POST /api/classrooms/homeroom  # Elementary homeroom creation
GET /api/subjects/core         # Core subjects for auto-assignment
POST /api/teacher-assignments/auto-assign  # Manual trigger
GET /api/teachers/{id}/assigned-subjects   # Teacher's current subjects
```

**Database Enhancements:**
```sql
-- New table for teacher-subject assignments
CREATE TABLE teacher_subject_assignments (
    id UUID PRIMARY KEY,
    teacher_id UUID REFERENCES users(id),
    subject_id UUID REFERENCES subjects(id),
    classroom_id UUID REFERENCES classrooms(id),
    assignment_type VARCHAR(20), -- 'AUTO', 'MANUAL', 'SWAPPED'
    assigned_date DATE,
    is_active BOOLEAN DEFAULT true
);

-- Enhanced subjects table flags
ALTER TABLE subjects ADD COLUMN is_homeroom_default BOOLEAN DEFAULT false;
ALTER TABLE subjects ADD COLUMN auto_assign_elementary BOOLEAN DEFAULT false;
```

**Core Logic Implementation:**
- Elementary classroom creation triggers auto-assignment
- New core subject creation propagates to existing teachers
- Assignment tracking and audit trail
