### Elementary School (K-5) - Homeroom Intelligence
#### Auto-Assignment Logic:
1. **Homeroom Creation:** Creating "3rd Grade Homeroom" automatically assigns:
   - Mathematics ✅
   - English Language Arts ✅  
   - Science ✅
   - Social Studies ✅
   - Reading ✅

2. **New Core Subject Propagation:** When admin creates new "Core/Homeroom Default" subject:
   - Automatically assigned to ALL existing elementary teachers
   - Ensures curriculum consistency across grades

3. **Teacher Swap System:** 
   - Teacher dashboard shows "My Assigned Subjects"
   - One-click subject swapping with other teachers
   - Example: "Mrs. Johnson swaps Math with Mr. Brown"

#### Classroom Creation Flow:
```
1. Admin creates rooms: "Room 101", "Room 102", etc.
2. Admin creates "3rd Grade Homeroom - Mrs. Johnson - Room 101"
3. System auto-assigns all core subjects to Mrs. Johnson
4. Mrs. Johnson can swap individual subjects via teacher dashboard
```

### Middle School (6-8) - Subject-Specific Model
#### Manual Assignment Approach:
1. **Deliberate Classroom Creation:** Each subject requires separate classroom
2. **Teacher Flexibility:** Teachers can teach multiple subjects in same room
3. **Room Efficiency:** Physical rooms used across multiple subject periods

#### Classroom Creation Flow:
```
1. Admin creates "Room 205" 
2. Admin creates "7th Grade ELA - Mr. Smith - Room 205"
3. Admin creates "7th Grade Social Studies - Mr. Smith - Room 205"
4. Same teacher, same room, different subjects/student groups
```
